# Програмний проєкт 6 — сопрограми C++20

Виконав: Максимов Гліб, група К-28. Варіант 6.

## Умова

Написати сопрограму, що генерує послідовність випадкових натуральних чисел з
проміжку [1, 256]. Для парних чисел сопрограма має передавати керування
сопрограмі A, яка виводить число. Для непарних чисел сопрограма має передавати
керування сопрограмі B, яка виводить квадрат числа. Реалізувати логіку передачі
керування в контролері очікування.

## Структура

| Файл | Призначення |
|------|-------------|
| `include/task.h` | Тип сопрограми `Task` (RAII-обгортка над `coroutine_handle`) |
| `include/transfer_controller.h`, `src/transfer_controller.cpp` | Контролер очікування `TransferController` та його awaiter-и |
| `include/coroutines.h`, `src/coroutines.cpp` | Сопрограми: генератор, A (`printNumber`), B (`printSquare`) |
| `include/config.h`, `src/config.cpp` | Читання та перевірка вхідного файлу |
| `include/demo.h`, `src/demo.cpp` | Демо: створення сопрограм та запуск |
| `src/main.cpp` | Точка входу, обробка помилок |
| `examples/` | Приклади коректних та некоректних вхідних файлів |

## Як це працює

Генератор робить `co_await controller.dispatch(n)`. Awaiter `DispatchAwaiter`
у `await_suspend` запам'ятовує дескриптор генератора і число та призначає
наступною сопрограму A (парне число) або B (непарне). Генератор не знає, хто
обробить число.

Сопрограми A і B після виводу роблять `co_await controller.returnToGenerator()`,
і `ReturnAwaiter` призначає наступним генератор.

Метод `TransferController::run` у циклі відновлює ту сопрограму, яку призначив
останній awaiter. Тому стек не росте незалежно від кількості чисел і рівня
оптимізації. Коли генератор вичерпує кількість чисел, він завершується, цикл
зупиняється, і керування повертається в `main`. Усі кадри сопрограм знищуються
деструкторами `Task`.

## Збирання

Потрібні CMake ≥ 3.16 та компілятор з підтримкою C++20 (GCC ≥ 11, Clang ≥ 14, MSVC 2019+).

```bash
cmake -S . -B build
cmake --build build
```


## Формат вхідного файлу

Текстовий файл, який містить одне або два цілі числа, розділені пробілами або
переводами рядка:

1. **Кількість чисел** — обов'язкове, ціле в межах `[1, 1000000]`.
2. **Seed** генератора — необов'язкове, ціле в межах `[0, 4294967295]`.
   Якщо не вказано, використовується випадковий seed (`std::random_device`).

Усе, що стоїть після символу `#` до кінця рядка, вважається коментарем.
Порожні рядки ігноруються.

Приклад:

```
# Кількість чисел та seed генератора
20 2026
```

## Обробка помилок

Програма повідомляє про помилку та завершується з кодом `1`, якщо:

- не передано шлях до файлу або передано зайві аргументи;
- файл не вдалося відкрити або прочитати;
- файл порожній (немає кількості чисел);
- значення не є цілим невід'ємним числом (`12abc`, `-5`, `1.5`);
- значення поза допустимими межами (`0`, `99999999999`);
- у файлі більше двох значень.

## Формат виводу

```
      1. A: 134
      2. B:  57^2 = 3249
```

Номер кроку, назва сопрограми (A або B) та результат її роботи.
